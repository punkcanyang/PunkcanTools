# Random Old Article

一个 Obsidian 插件，用于随机挑选陈旧的文章来阅读，帮助您回顾过去的内容。

## 功能特点

- **随机挑选陈旧文章**：从您的笔记库中随机选择一篇文章
- **智能去重**：避免重复挑选近期（可配置，默认一年）已经阅读过的文章
- **可配置参数**：
  - 设置冷却期天数（文章被阅读后多少天内不再被选）
  - 设置最小文件年龄（只选择创建足够久的文章）
  - 排除特定文件夹
  - 包含/不包含子文件夹

## 使用方法

### 安装

1. 克隆或下载此仓库到您的 Obsidian 插件文件夹
2. 运行 `npm install` 安装依赖
3. 运行 `npm run build` 构建插件
4. 在 Obsidian 中启用此插件

### 使用

1. **点击工具栏图标**：点击左侧工具栏的骰子图标即可随机挑选一篇文章
2. **使用命令面板**：按 `Cmd/Ctrl + P`，搜索 "挑选随机旧文章" 命令
3. **清除历史**：如果需要重置历史记录，可以使用 "清除阅读历史" 命令

### 设置

打开设置面板，可以配置：
- **冷却期（天）**：默认为 365 天，即一年内读过的文章不会再次被选中
- **最小文件年龄（天）**：默认为 30 天，只选择创建至少 30 天的文章
- **包含子文件夹**：是否在所有子文件夹中搜索
- **排除的文件夹**：可以指定要排除的文件夹路径

## 开发

```bash
# 安装依赖
npm install

# 开发模式（自动重新构建）
npm run dev

# 生产构建
npm run build
```
