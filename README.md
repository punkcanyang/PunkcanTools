# PunkcanTools 🛠️

个人实用工具集，包含各类自动化脚本和效率工具。

## 📦 项目列表

| 工具 | 描述 |
|------|------|
| [astro-chart](./astro-chart/) | 星盘计算工具，输入时间地点，生成行星位置、宫位、相位 |
| [vless-reality-setup](./vless-reality-setup/) | VLESS + Reality 一键部署脚本，支持 Debian/Ubuntu/CentOS |
| [word2md](./word2md/) | Word 文档转 Markdown 转换工具 |

## 🚀 快速开始

### 星盘计算工具

```bash
cd astro-chart
npm install
npm start
# 访问 http://localhost:3000
```

### VLESS Reality 部署

```bash
cd vless-reality-setup

# Debian/Ubuntu
sudo bash install.sh

# CentOS/RHEL
sudo bash install-centos.sh
```

### Word 转 Markdown

```bash
cd word2md
npm install
npm start
```
