# Doc Tools

文件轉換工具整合版（Tauri）：

- HTML -> PDF（可勾選是否顯示每頁底部置中頁碼）
- Word (.docx) -> Markdown

## 歷史模組收納

- `legacy-projects/html-book-pdf`：舊版 HTML -> PDF 專案
- `legacy-projects/word2md`：舊版 Word -> Markdown 專案

## 開發

```bash
cd /Users/punkcan/SourceCode/PunkcanTools/doc-tools
npm install
npm run dev
```

## 打包

```bash
cd /Users/punkcan/SourceCode/PunkcanTools/doc-tools
npm run build
```
